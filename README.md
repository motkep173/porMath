# מתמטיקה עם פורת: מאגר מבחנים להכנה לבגרות

אתר לתרגול לקראת הבגרות. אפשר לפתוח בו מבחן שלם לפי השם שלו, למשל „בגרות 035571 – קיץ תשפ״ד (2024), מועד א׳”,
או לבחור נושא, למשל סדרות או הסתברות, ולקבל את כל השאלות בנושא מכל המבחנים. יש באתר שלוש קטגוריות:
בגרויות, מבחנים מבתי ספר והמבחנים שלנו.

כל שאלה שמורה בנפרד, כטקסט עם נוסחאות TeX. לכן אפשר לחפש בשאלות, לסנן אותן לפי נושא ולבנות מהן חוברת PDF.

## מבנה

| נתיב | מה יש בו |
|---|---|
| `data/exams.json` | רשימת כל המבחנים: קטגוריה, שאלון, שם מלא, שנה, מועד וקובצי המקור |
| `data/questions/<examId>.json` | השאלות של מבחן אחד, ולכל שאלה נושא, תת־נושא ופתרון (או `null`) |
| `data/taxonomy.json` | רשימת הנושאים ותתי־הנושאים, לפי סדר תוכנית הלימודים |
| `data/img/` | שרטוטים שנחתכו מהמבחנים |
| `data/course.json` | שם האתר והכותרות |
| `app/template.html` | עיצוב האתר והקוד שלו |
| `tools/` | סקריפטים: בדיקת הנתונים, בניית האתר ובניית החוברת |
| `docs/` | המדריך לתמלול, פורמט הנתונים, וההבדלים מהתבנית (`project-notes.md`) |
| `index.html`, `booklet.pdf` | האתר והחוברת. הם נוצרים מהנתונים, ולא עורכים אותם ידנית |

קובצי ה־PDF המקוריים נשמרים בתיקייה `exams/`, שלא נכנסת ל־git.

## בנייה

```bash
cd tools && npm install && cd ..            # פעם אחת
python3 tools/validate.py                   # בודק את הנתונים ואת כל הנוסחאות
python3 tools/build.py                      # בונה את index.html
python3 tools/booklet.py                    # בונה את booklet.pdf
```

קישור ישיר למבחן: `index.html#<examId>`, למשל `index.html#b571-2024-summer-a`.

## הוספת מבחן

1. שמים את ה־PDF ב־`exams/` ומוסיפים שורה ל־`data/exams.json`.
2. מתמללים את המבחן ל־`data/questions/<examId>.json`, לפי `docs/transcription-guide.md` ו־`docs/project-notes.md`.
3. מריצים validate, build ו־booklet.
